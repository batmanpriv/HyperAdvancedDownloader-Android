## 🔥 هایپر ادونسد دانلودر چیه؟

**HAD** یه دانلودر اندرویدی کاملاً بومی و حرفه‌ایه که با **کاتلین** و **جتپک کامپوز** نوشته شده. این برنامه قابلیت‌های دانلود رو به سطح پی‌سی می‌رسونه، اما توی گوشی موبایل.

فرقی نمی‌کنه که می‌خوای یه فیلم ۴K دانلود کنی، یه استریم HLS رو ضبط کنی، یه تورنت لینوکس بگیری، کل یه سایت رو آفلاین کنی، یا از روی پی‌سی دانلودات رو کنترل کنی — HAD همه‌ش رو با **سرعت، قابلیت اطمینان و ظاهر شیک** انجام میده.

## 🚀 قابلیت‌ها به زبان خودمونی

### ⚡ هسته دانلود (چندتردی)

| قابلیت | چطور استفاده کنم؟ | کی به کارم میاد؟ |
|--------|-------------------|------------------|
| **دانلود چندتردی** | توی صفحه افزودن دانلود، تعداد ترد رو انتخاب کن (۱ تا ۳۲). پیش‌فرض: ۴ | فایل‌های بزرگ (بالای ۱ گیگ) رو با سرعت بالا دانلود کنی. فایل رو تکه‌تکه می‌کنه و همزمان می‌کشه |
| **ادامه دانلود** | خودش فعاله. هر دانلود متوقف شده رو با دکمه Retry ادامه بده | وقتی نت قطع شد، گوشی خاموش شد، یا برنامه بسته شد — از همون بایت قبلی ادامه میده نه از صفر |
| **ذخیره خودکار پیشرفت** | خودکار. هر چند ثانیه یکبار ذخیره میشه | هیچوقت پیشرفت دانلودت رو از دست نمیدی؛ حتی اگه برنامه رو بزنی force-stop |
| **صف هوشمند** | توی Settings → Download Defaults تعداد دانلود همزمان رو تنظیم کن (پیش‌فرض: ۲) | وقتی کلی دانلود داری و می‌خوای پهنای باندت رو کنترل کنی |
| **آینه (Mirror)** | توی Advanced Options می‌تونی لینک‌های جایگزین اضافه کنی (هر خط یه لینک) | وقتی سرور اصلی کند یا نامطمئنه — خودش سریع‌ترین آینه رو انتخاب می‌کنه |
| **بافر تطبیقی** | خودکار بر اساس سرعت اینترنت | حافظه رو بهینه می‌کنه؛ برای اینترنت ضعیف بافر کم، برای قوی بافر زیاد |
| **محدودیت سرعت** | توی تنظیمات حداکثر سرعت رو به کیلوبایت بر ثانیه تنظیم کن (۰=نامحدود) | وقتی اینترنت محدود داری یا نمی‌خوای کل پهنای باند رو اشغال کنه |

### 📺 دانلود استریم و HLS

| قابلیت | چطور استفاده کنم؟ | کی به کارم میاد؟ |
|--------|-------------------|------------------|
| **تشخیص خودکار HLS** | لینک .m3u8 رو پیست کن — خودش حالت HLS رو فعال می‌کنه | وقتی می‌خوای از سایت‌هایی مثل یوتیوب، ویمئو یا هر پلتفرم HLS ویدئو دانلود کنی |
| **انتخاب کیفیت** | پلی‌لیست master رو شناسایی می‌کنه؛ خودش بهترین کیفیت رو انتخاب می‌کنه | برای تماشای آفلاین — بهترین کیفیت موجود رو می‌گیری |
| **سگمنت‌های موازی** | توی Advanced Options تعداد ترد رو تنظیم کن | دانلود سریع‌تر استریم‌های چندبخشی |
| **رمزگشایی AES-128** | کلید رو خودش از پلی‌لیست می‌گیره | دانلود استریم‌های DRM دار (مثل محتوای پریمیوم) |
| **ضبط استریم زنده** | روی لینک .m3u8 زنده شروع به دانلود کن | ضبط رویدادهای زنده، مسابقات یا استریم‌ها — سگمنت‌های جدید رو مدام دانلود می‌کنه |
| **پشتیبانی fMP4** | سگمنت‌های MP4 تکه‌تکه شده رو مدیریت می‌کنه | دانلود فرمت‌های مدرن استریم |
| **استخراج صدا/زیرنویس** | خودکار (در صورت موجود بودن) | گرفتن محتوای چندزبانه برای پخش آفلاین |

### 🌊 تورنت و مگنت

| قابلیت | چطور استفاده کنم؟ | کی به کارم میاد؟ |
|--------|-------------------|------------------|
| **فایل‌های .torrent** | تب Torrent → دکمه + → فایل .torrent رو انتخاب کن | دانلود از تورنت‌های مبتنی بر ترکر |
| **لینک مگنت** | توی تب Torrent روی آیکون زنجیر بزن → لینک magnet: رو پیست کن | دانلود سریع بدون نیاز به دانلود فایل .torrent |
| **دریافت متادیتا از DHT** | وقتی لینک مگنت متادیتا نداره، خودش از شبکه DHT می‌گیره | گرفتن اطلاعات لینک‌های مگنت از شبکه DHT |
| **پشتیبانی از چند ترکر** | خودکار UDP + HTTP announce | پیدا کردن سریع‌تر هم‌په‌ها از ترکرهای مختلف |
| **انتخاب فایل‌ها** | توی TorrentStartDialog فایل‌های مورد نظر رو انتخاب کن | دانلود فقط فایل‌های خاص از یه تورنت چندفایلی |
| **تأیید تکه‌ها** | چکسوم SHA-1 به صورت خودکار بررسی میشه | اطمینان از اینکه داده‌ها خراب نشدن |
| **مدیریت هم‌په‌ها** | با الگوریتم rarest-first | بهینه‌سازی سرعت دانلود و کارایی شبکه |
| **حالت Endgame** | خودکار برای دانلودهای نزدیک به اتمام | دانلود موازی تکه‌های باقی‌مونده برای سریع‌ترین تکمیل |

### 🌐 مرورگر هوشمند (همون لحظه لینک‌ها رو کپچر می‌کنه)

| قابلیت | چطور استفاده کنم؟ | کی به کارم میاد؟ |
|--------|-------------------|------------------|
| **چند تب** | روی عدد تب‌ها بزن → تب جدید | گشتن همزمان توی چندتا سایت |
| **ردیابی خودکار فایل** | معمولی وبگردی کن؛ فایل‌ها خودش تشخیص داده میشن | پیدا کردن فایل‌های قابل دانلود از هر سایتی بدون اینکه خودت لینک‌ها رو استخراج کنی |
| **پل جاوااسکریپت** | HAD خودش اسکریپت رهگیری رو تزریق می‌کنه | تشخیص محتوای داینامیک (XHR، fetch، المنت‌های ویدئو) |
| **حالت ناشناس** | منوی سه نقطه → حالت ناشناس | مرور خصوصی — هیچ تاریخچه، کوکی یا کشی ذخیره نمیشه |
| **نمایش دسکتاپ** | منوی سه نقطه → نمایش دسکتاپ | دسترسی به لینک‌ها یا محتوای مخصوص دسکتاپ |
| **پیست و برو** | منوی سه نقطه → پیست و برو | ناوبری سریع از لینک‌های توی کلیپ‌بورد |
| **پنل فایل‌های رهگیری شده** | روی نشان بنفش پایین سمت راست بزن | مرور و دانلود همه فایل‌های شناسایی شده در یکجا |

**نکته حرفه‌ای:** مرورگر HAD از مرورگرهای معمولی باهوش‌تره — درخواست‌های شبکه رو به صورت لحظه‌ای مانیتور می‌کنه و لینک‌هایی رو می‌گیره که مرورگرهای دیگه ازشون رد میشن.

### 🔍 اسکرپر لینک (حرفه‌ای)

| قابلیت | چطور استفاده کنم؟ | کی به کارم میاد؟ |
|--------|-------------------|------------------|
| **اسکرپ هر صفحه** | آیکون کره → پیست URL → اسکرپ لینک‌ها | پیدا کردن همه محتوای قابل دانلود از یه صفحه بدون جستجوی دستی |
| **فیلتر نوع** | فیلتر بر اساس VIDEO, AUDIO, ARCHIVE, DOCUMENT و... | تمرکز روی نوع محتوای خاص |
| **فیلتر پسوند** | فیلتر بر اساس .mp4, .mp3, .zip, .pdf و... | پیدا کردن فایل‌های با پسوند خاص |
| **فیلتر کیفیت** | فیلتر بر اساس 4K, 1080p, 720p و... | انتخاب فقط ویدئوهای با کیفیت بالا |
| **دانلود دسته‌ای** | چند لینک رو انتخاب کن → دانلود همه | گرفتن چندین فایل با هم |
| **صف دسته‌ای** | چند لینک رو انتخاب کن → قرار دادن در صف | اضافه کردن چندین فایل به صف بدون شروع دانلود |
| **اضافه مستقیم** | روی هر لینک + بزن → پنجره دانلود جدید باز میشه | تنظیم تنظیمات خاص برای هر لینک |
| **سیستم کش** | نتایج کش میشن؛ دکمه Re-scrape موجوده | مرور صفحات اسکرپ شده بدون دانلود مجدد |

**نکته حرفه‌ای:** عالیه برای دانلود کل پلی‌لیست‌ها، مجموعه‌های چندقسمتی، یا همه اسناد یه صفحه در یک حرکت!

### 📦 آرشیو وب (آفلاین کردن سایت)

| قابلیت | چطور استفاده کنم؟ | کی به کارم میاد؟ |
|--------|-------------------|------------------|
| **حالت تک صفحه** | Web Archive → + → انتخاب "تک صفحه" | ذخیره یه مقاله، دستور پخت یا صفحه برای مطالعه آفلاین |
| **خزش کامل سایت** | انتخاب "کل سایت" → تنظیم حداکثر صفحات | آرشیو کردن کل سایت‌ها برای مرور آفلاین |
| **دانلود دارایی‌ها** | CSS، JS، تصاویر، فونت‌ها خودکار ذخیره میشن | رندر کامل آفلاین — همه چیز شامل میشه |
| **بازنویسی لینک‌ها** | همه لینک‌های داخلی خودکار بازنویسی میشن | صفحات دقیقاً مثل حالت آنلاین کار می‌کنن |
| **پشتیبانی از دارایی‌های خارجی** | فعال/غیرفعال کردن "دانلود دارایی‌های خارجی" | شامل کردن محتوای دامنه‌های دیگه |
| **پشتیبانی از مسیرهای هش** | فعال/غیرفعال برای SPA (برنامه‌های تک صفحه‌ای) | آرشیو کردن سایت‌های مدرن جاوااسکریپتی |
| **مینی‌فای** | فعال/غیرفعال کردن برای خروجی HTML | حجم آرشیو کوچیک‌تر |
| **پشتیبانی از احراز هویت** | اضافه کردن کوکی توی Advanced Options | آرشیو کردن صفحات پشت لاگین |

**نکته حرفه‌ای:** عالیه برای ذخیره مستندات، مقالات خبری، آموزش‌ها یا هر محتوایی که می‌خوای آفلاین بهش دسترسی داشته باشی.

### 📡 سرور کنترل از راه دور

| قابلیت | چطور استفاده کنم؟ | کی به کارم میاد؟ |
|--------|-------------------|------------------|
| **شروع سرور** | منوی کناری → سرور راه‌دور → روشن کن | کنترل دانلودها از پی‌سی وقتی گوشی روی وای‌فای مشترکه |
| **دانلود تک لینک** | توی Web UI لینک رو پیست کن → دانلود الآن | فرستادن لینک‌های دانلود تکی از پی‌سی به گوشی |
| **دانلود دسته‌ای** | چند لینک رو پیست کن (هر خط یه لینک) → دانلود همه | فرستادن کلی لینک با هم |
| **پشتیبانی از صف** | دانلود الآن یا اضافه به صف | انتخاب دانلود فوری یا برنامه‌ریزی صف |
| **تاریخچه درخواست‌ها** | مشاهده همه درخواست‌های گذشته توی Web UI | دانلود مجدد یا قرار دادن مجدد در صف URLهای قبلی |
| **وضعیت زنده** | تعداد درخواست‌ها، کلاینت‌های متصل، آخرین درخواست | مانیتورینگ فعالیت سرور |

**نکته حرفه‌ای:** آدرس سرور روی گوشی نشون داده میشه — فقط کافیه توی مرورگر پی‌سی‌ت تایپ کنی و از میز کارت دانلودها رو کنترل کنی!

### 🔄 موتور تلاش مجدد (هوشمند)

| کد وضعیت | استراتژی | کی می‌بینی‌اش؟ |
|----------|----------|---------------|
| **۴۰۳ (دسترسی ممنوع)** | چرخش User-Agent → اضافه کردن هدرهای مرورگر | سایت‌هایی که دانلودرها رو بلاک می‌کنن؛ HAD خودش رو شبیه مرورگر واقعی می‌کنه |
| **۴۲۹ (محدودیت نرخ)** | بک‌آف نمایی (۵ ثانیه → ۱۲۰ ثانیه) | وقتی از یه سرور زیاد دانلود می‌کنی |
| **۵۰۳ (سرویس در دسترس نیست)** | تأخیر افزایشی + چرخش UA | سرور شلوغه؛ HAD صبر می‌کنه و دوباره تلاش می‌کنه |
| **تایم‌اوت** | تأخیر افزایشی تا ۶۰ ثانیه | اتصالات کند یا مشکلات شبکه |
| **خطاهای ۵۰۰-۵۹۹** | بک‌آف نمایی با محدودیت تلاش | خطاهای سرور؛ HAD هوشمندانه تلاش مجدد می‌کنه |

| **تراشه‌های از پیش تعیین‌شده** | امشب، نیمه‌شب، سحر توی برنامه‌ریز | برنامه‌ریزی سریع بدون تایپ دستی |
| **توقف/ادامه خودکار** | دانلودها خارج از پنجره متوقف، با باز شدن پنجره ادامه پیدا می‌کنن | صرفه‌جویی در پهنای باند در ساعات اوج مصرف یا استفاده از اینترنت شبانه |
| **شمارش معکوس زنده** | زمان باقی‌مونده توی نوتیفیکیشن نمایش داده میشه | دقیقاً می‌دونی دانلودها کی شروع میشن |

**نکته حرفه‌ای:** یه برنامه سراسری تنظیم کن (مثلاً ۲۳:۰۰ → ۰۶:۰۰) تا همه دانلودهای بزرگت رو یک‌شبه انجام بده!

## 🚀 شروع سریع

### پیش‌نیازها
- اندروید استودیو Hedgehog یا جدیدتر
- JDK 17
- Android SDK 36

### مراحل

```bash
git clone https://github.com/batmanpriv/HyperAdvancedDownloader-Android.git
cd HyperAdvancedDownloader-Android
```

در اندروید استودیو باز کن:
```
File → Open → پوشه HyperAdvancedDownloader-Android رو انتخاب کن → منتظر بمان تا Gradle sync کامل بشه
```

روی دستگاه اجرا کن:
```
Run → Run 'app' (دستگاه یا شبیه‌ساز خود را انتخاب کن)
```

ساخت APK انتشار:
```
Build → Generate Signed Bundle/APK → APK → مراحل امضای دیجیتال رو دنبال کن
```
